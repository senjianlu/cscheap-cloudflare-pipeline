## 系统形态

单一可分发单元、扁平根布局:一个只在 CI 与本地运行的 Node 命令行,加一份契约库与可复用 GitHub 工作流;
不部署任何服务。

```
内容仓(Git:MDX + JSON)──按 tag 调用可复用工作流──► 本仓命令行
                                                        │ 校验 → 编译为 AST → 写入 → 切指针
                                                        ▼
                                              Cloudflare D1 + R2
                                                        ▲ 只读,钉同一版本的契约类型
                                                     渲染端
```

当前进度:

| 部分 | 状态 |
|---|---|
| 内容契约 v1(`contract/`、`schemas/`、`migrations/`、`templates/`) | 已实现 |
| 校验命令行、MDX 编译、发布 / 回滚 / 清理、可复用工作流 | 尚未实现 |
